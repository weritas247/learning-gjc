# Learning GJC

가재코드(Gajae-Code, `gjc`)를 한국어로 소개하는 학습용 HTML 가이드 모음입니다.

- `gajae-code-guide-ko.html` — 처음 사용하는 개발자를 위한 입문 가이드
- `gajae-code-intermediate-ko.html` — 작업 시스템과 검증 흐름에 초점을 둔 중급 가이드

각 HTML 파일은 브라우저에서 직접 열어 읽을 수 있습니다. 이미지 자산은 원본 [Yeachan-Heo/gajae-code](https://github.com/Yeachan-Heo/gajae-code) 저장소를 참조합니다.

## 참고

가재코드는 베타 단계의 코딩 에이전트 러너입니다. 실제 코드 변경, 인증, 결제, 삭제, 배포 작업은 diff와 테스트 결과를 직접 검토하세요.
